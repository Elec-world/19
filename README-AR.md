# عالم الالكترونيات — Electronic World

هذه النسخة تحمل هوية **عالم الالكترونيات** في العنوان والأيقونة والخلفية.

## الملفات المهمة
- `index.html` الصفحة الرئيسية
- `jb.html` صفحة التشغيل
- `cache.appcache` ملف التخزين المؤقت
- `icon.png` أيقونة الموقع
- `background.png` خلفية الموقع

> تم تنظيف ملف `cache.appcache` ليشير فقط إلى الملفات الموجودة فعليًا في المشروع، مع إزالة مراجع الملفات غير الموجودة.
